# Global Orbit Bot

Бот для [Global Orbit](https://globalorbit.online): сам збирає коробки на карті, а якщо попросити — ще й б'є NPC чи проходить гейт. 
Встановлювати нічого не треба: це один скрипт, який вставляють у консоль браузера на сторінці гри.

## Що вміє

- **Збирає коробки**, найближчі першими. За замовчуванням бере `BONUS_BOX` і `CARGO_BOX`. Коли поруч нічого немає, літає картою й шукає, не підлітаючи до її краю.
- **Б'є NPC**, якщо ввімкнути бій. Коробки все одно в пріоритеті: бот злітає по коробку й повертається до своєї цілі.
- **Оминає небезпечних NPC**: відлітає від них і не бере коробок поруч.
- **Відступає, коли мало HP**: кидає все, тікає від NPC і чекає, поки корабель відремонтується.
- **Проходить гейт** (галактичні ворота): стрибає в портал, раунд за раундом б'є NPC, «тягаючи» їх за собою, а коли HP мало — перемикається на швидкісну конфігурацію, відлітає, ремонтується й повертається.
- **Чекає, коли трюм повний.**
- **Поводиться як людина**: не викликає функції гри напряму, а клікає по карті, як мишею; веде курсор дугою, робить випадкові паузи й іноді бере не найближчу коробку.

## Як запустити

1. Відкрий [globalorbit.online/map-revolution](https://globalorbit.online/map-revolution) і дочекайся, поки завантажиться карта.
2. Відкрий консоль браузера: `F12` → вкладка **Console** (у Chrome — одразу `Ctrl+Shift+J`, на macOS `Cmd+Option+J`).
3. Скопіюй увесь вміст [`main.js`](main.js), встав у консоль і натисни `Enter`.

Сам бот нічого не починає: пише в консоль, що готовий, і чекає команди.

```
[goBot 14:02:11] готовий, чекаю команди: goBot.start() — збирати коробки, …
```

Що робити, кажеш командою: `goBot.start()` — збирати коробки, `goBot.startKillNpc()` — ще й бити NPC, `goBot.startPassGalaxyGate()` — пройти гейт ([усі команди](#команди)). Зупинити — `goBot.stop()`. Щоб оновити бота, просто встав нову версію `main.js`: стара зупиниться сама, а нову запусти потрібною командою.

Корисно знати:

- Chrome і Firefox при першій вставці в консоль просять надрукувати `allow pasting`. Надрукуй і встав скрипт ще раз.
- Поки бот працює, не води мишею над картою: гра стежить і за твоїм курсором, і бот збиватиметься.
- Вкладку з грою можна лишити у фоні: таймер бота працює у Web Worker, тож браузер його не гальмує.

## Команди

| Команда                       | Що робить                                                                |

## Приклади

### Коробки й NPC

```js
goBot.startKillNpc()
```

Бот б'є найближчого NPC і підлітає, коли той далі за `npcRange`. Побачивши коробку, злітає по неї — лазери тим часом стріляють далі — і повертається до тієї ж цілі. `goBot.stopKillNpc()` вимикає бій, а коробки бот збирає й далі.

### Бити тільки певних NPC

```js
goBot.config.npcInclude = ['Streuner', 'Lordakia']  // частина імені, регістр неважливий
goBot.config.npcExclude = ['Boss']                  // але не боси
goBot.startKillNpc()
```

Як звуть NPC довкола, покаже `goBot.npcs()`.

### Які коробки брати

```js
// тільки BONUS_BOX
goBot.config.include = ['BONUS_BOX']

// усі, крім руди
goBot.config.include = null
goBot.config.exclude = ['ORE']
```

Типи коробок: `BONUS_BOX`, `CARGO_BOX`, `FROM_SHIP`, `ORE`, `ALIEN`, `GIFT_BOXES`, `PIRATE_BOOTY`, `PIRATE_BOOTY_RED`, `PIRATE_BOOTY_BLUE`, `PIRATE_BOOTY_GOLD`. Фільтр шукає підрядок, тож `'PIRATE_BOOTY'` — це всі піратські скрині. Які коробки лежать поруч, покаже `goBot.boxes()`.

### Тікати раніше

```js
// тікати вже при 35% HP і повертатися з 90%
Object.assign(goBot.config, { retreatHpPct: 35, retreatUntilHpPct: 90 })

// не тікати взагалі
goBot.config.retreatHpPct = 0
```

### Гейт

Потрібні дві конфігурації корабля: **1-ша для бою** (максимум лазерів і щити) і **2-га для втечі** (генератори швидкості й щити). У гейт заходь на 1-й.

```js
// сам підведи корабель до порталу гейта (ближче ніж на 700 од.)
goBot.startPassGalaxyGate()   // гейт з 1-го раунду
goBot.startPassGalaxyGate(4)  // або: гейт продовжується з 4-го раунду
```

Якщо бот перед тим збирав коробки, спершу `goBot.stop()`: поки він літає картою, корабель відходить від порталу.

Що робить бот:

1. Ремонтується, якщо HP чи щит нижче `gateRepairHpPct`/`gateRepairShieldPct`, підлітає в сам портал і тисне `J`.
2. Чекає відліку й б'є NPC по одному, «тягаючи» їх: не стоїть, а відходить від цілі навскіс, тримаючи її на `gateKiteDist`, так що лазер дістає ціль, а ціль і решта зграї доганяють і рідше влучають. Хто в зграї ближче за `gateCrowdDist`, відштовхує курс.
3. Коли HP нижче `gateFleeHpPct`, а щит не більше `gateFleeShieldPct` (або HP нижче `gatePanicHpPct`, хоч би який щит), — `C` (2-га конфігурація), лазери геть і втеча: поки NPC не зникнуть з очей, а тоді ще щонайменше на `gateFleeDist`. Потім `C` (1-ша), і бот стоїть, поки гра не відремонтує корабель. Відремонтувавшись, летить туди, де бачив NPC, і б'є далі. Якщо NPC прилетять самі, поки він ремонтується, а HP і щит уже на половині від порогів ремонту, — б'ється, інакше знову тікає.
4. Коли всіх NPC знищено й з'являються два портали, ремонтується, якщо треба, і летить у **лівий** — у наступний раунд.
5. Після `gateRounds`-го раунду летить у **правий** портал, додому, і зупиняється.

Бот зупиняється й тоді, коли корабель знищено або не вдається стрибнути. Якщо запустити `startPassGalaxyGate()` посеред раунду, коли порталів на карті нема, бот вважає, що він уже в гейті, і б'є NPC далі; номер раунду тоді передай аргументом.

Чому є `gatePanicHpPct`: щит бере на себе лише частину урону, тож поки він не порожній, HP теж тане. До того ж, судячи з публічного коду сервера, HP не ремонтується, поки ти сам стріляєш, а щит ремонтується, щойно 10 с по тобі не влучали. Після довгого бою з повільними NPC щит буває повний, а HP низьке, і правило «щит 0%» спрацювало б надто пізно.

### Тільки подивитися

```js
goBot.config.dryRun = true   // нічого не клікати, тільки друкувати таблиці
goBot.start()
goBot.config.dryRun = false  // назад до роботи
```

Поки бот працює, раз на 2 секунди він друкує таблицю коробок, а з увімкненим боєм — і NPC.

## Налаштування

Усі налаштування — в об'єкті `CONFIG` на початку `main.js`, до кожного є коментар. Змінити їх можна двома способами:

- **На льоту**, через `goBot.config`. Діє одразу, але тільки до перезавантаження сторінки:

  ```js
  goBot.config.npcRange = 450
  Object.assign(goBot.config, { scanRadius: 3000, stopWhenCargoFull: false })
  ```

  Міняй окремі поля: якщо замінити об'єкт цілком (`goBot.config = {…}`), бот цього не помітить.

- **Назавжди** — відредагуй `CONFIG` у `main.js`, перш ніж вставляти скрипт.

Нижче основні налаштування. Решта (політ, паузи й інша «людськість») описана в самому `CONFIG`.

### Коробки

| Налаштування        | За замовчуванням             | Що робить                                                   |
|---------------------|------------------------------|-------------------------------------------------------------|
| `include`           | `['BONUS_BOX', 'CARGO_BOX']` | які типи брати (підрядки); `null` — усі                     |
| `exclude`           | `[]`                         | які типи не брати, напр. `['ORE']`                          |
| `scanRadius`        | `0`                          | шукати коробки не далі за стільки одиниць; `0` — без ліміту |
| `stopWhenCargoFull` | `true`                       | стояти, коли трюм повний                                    |
| `dryRun`            | `false`                      | тільки дивитися, нічого не клікати                          |

### NPC

| Налаштування    | За замовчуванням   | Що робить                                                                   |
|-----------------|--------------------|-----------------------------------------------------------------------------|
| `npcInclude`    | `null`             | кого бити (частина імені, регістр неважливий); `null` — усіх                |
| `npcExclude`    | `[]`               | кого не бити, напр. `['Boss']`                                              |
| `npcAvoid`      | `['Boss Sibelon']` | від кого відлітати                                                          |
| `npcAvoidDist`  | `1500`             | триматися від них далі, ніж на стільки одиниць                              |
| `npcScanRadius` | `0`                | шукати NPC не далі за стільки одиниць; `0` — усіх, кого показує гра (~2000) |
| `npcRange`      | `550`              | підлітати до цілі, коли вона далі (лазер дістає на ~700)                    |
| `npcMinHpPct`   | `30`               | не починати новий бій, коли HP нижче, %                                     |
| `npcStuckMs`    | `20000`            | кинути ціль, якщо стільки мс її HP і щит не падають                         |

### Відступ

| Налаштування        | За замовчуванням | Що робить                                                    |
|---------------------|------------------|--------------------------------------------------------------|
| `retreatHpPct`      | `20`             | при якому HP тікати, %; `0` — ніколи                         |
| `retreatUntilHpPct` | `75`             | до якого HP ремонтуватися перед поверненням, %               |
| `retreatSafeDist`   | `1500`           | тікати, поки NPC ближче за стільки одиниць або по тобі б'ють |

### Гейт

| Налаштування          | За замовчуванням | Що робить                                                                         |
|-----------------------|------------------|-----------------------------------------------------------------------------------|
| `gateRounds`          | `10`             | раундів у гейті; після останнього — правий портал, додому                         |
| `gateStartDist`       | `700`            | на старті портал гейта має бути ближче за стільки одиниць                         |
| `gateFleeHpPct`       | `30`             | тікати на 2-й конфігурації, коли HP нижче цього, %...                             |
| `gateFleeShieldPct`   | `0`              | ...а щит не більше цього, %                                                       |
| `gatePanicHpPct`      | `15`             | нижче цього тікати, хоч би який щит, %; `0` — вимкнено                            |
| `gateRepairHpPct`     | `90`             | до скількох HP ремонтуватись, перш ніж знову в бій чи в наступний раунд, %        |
| `gateRepairShieldPct` | `90`             | те саме для щита 1-ї конфігурації, %                                              |
| `gateFleeDist`        | `3000`           | скільки ще летіти, коли NPC уже зникли з очей                                     |
| `gateKiteDist`        | `560`            | на якій відстані тримати ціль, поки б'ємо (лазер дістає на ~700)                  |
| `gateCrowdDist`       | `500`            | інші NPC, ближчі за це, відштовхують курс                                         |
| `gateStuckMs`         | `15000`          | взяти іншу ціль, якщо стільки мс її HP і щит не падають                           |
| `gateSearchMs`        | `20000`          | скільки чекати наступну хвилю, перш ніж шукати NPC картою                         |

Зона безпеки для втечі й ремонту — `retreatSafeDist` з розділу «Відступ»: NPC ближче за неї вважаються загрозою.

## Якщо щось не так

| Що бачиш                                                       | Що робити                                                                                  |
|----------------------------------------------------------------|--------------------------------------------------------------------------------------------|
| `[goBot] не знайшов фрейм гри…`                                | Відкрий `/map-revolution`, дочекайся карти й встав скрипт ще раз.                          |
| `[goBot] карта ще не ініціалізована…`                          | Дочекайся входу в гру й встав скрипт ще раз.                                               |
| `[goBot] не дістав SceneManager з бандла гри`                  | Схоже, гру оновили й бандл змінився. Бота треба підлаштувати під нову версію.              |
| Коробка в `goBot.boxes()` «на екрані», але не «можна клікнути» | Її закриває вікно інтерфейсу (крізь вікна бот не клікає) або вона біля самого краю екрана. |
| `трюм повний (…), чекаю`                                       | Звільни трюм — бот продовжить сам.                                                         |
| `HP не росте вже хвилину…`                                     | Тут корабель не ремонтується. Знизь `retreatUntilHpPct` або зупини бота.                   |
| Після `goBot.stop()` лазери стріляють далі                     | `stop()` лазерів не вимикає. Виклич `goBot.stopKillNpc()`.                                 |
| Корабель знищено                                               | Бот його не ремонтує: поки HP = 0, він просто чекає. У гейті — зупиняється.                |
| `підлети до порталу гейта ближче…`                             | Підведи корабель до порталу гейта й запусти знову; якщо бот літає — спершу `goBot.stop()`. |
| `стрибок не вийшов…`, `не вдалося стрибнути…`                  | Портал не прийняв стрибок. Бот пробує тричі, щоразу підлітаючи в самий центр порталу.      |
| `HP і щит не ростуть уже 30 с…`                                | Тут корабель не ремонтується. Бот іде далі з тим, що є.                                    |
| `goBot.status().гейт` довго показує `шукаю NPC`                | NPC загубив корабель і відлетів. Бот шукає там, де бачив його, а далі посередині карти.    |

## Як це працює

Якщо запущено гейт, бот проходить його ([докладно](#гейт)). Інакше щоразу береться за першу справу зі списку, яка зараз підходить:

1. HP нижче `retreatHpPct` — відступає.
2. Поруч NPC зі списку `npcAvoid` — відлітає.
3. Трюм повний — чекає (`stopWhenCargoFull`).
4. Видно потрібну коробку — летить по неї.
5. Увімкнено бій і є ціль — б'є NPC.
6. Інакше — літає картою й шукає.

**Доступ до гри.** Гра — це Vite ESM-бандл у `<iframe src="/spacemap/index.html">`. Повторний `import()` того самого URL усередині фрейму повертає той самий, уже виконаний модуль, тож бот дістає з нього живий `SceneManager`, а з того — `MapManager` зі станом карти: `map.boxes` (коробки), `map.hero` (твій корабель), `map.displayLayer` (камера).

**Збір.** Бот не викликає внутрішніх методів гри, а клікає: переводить світові координати коробки в екранні й шле туди `pointermove`/`pointerdown`/`pointerup`, як від миші. Далі все робить гра: `MapManager.onBoxClicked()` веде корабель до коробки, а коли той підлетить ближче ніж на 20 одиниць, `MapManager.update()` шле `sendCollectBoxRequest()`. Піратські скрині (`PIRATE_BOOTY`) збираються довго, тож на них бот вистоює `slowHoldMs` і нікуди не клікає: будь-який клік зірвав би збір.

**Політ.** Як у гравців: кнопка миші затиснута, курсор біля краю екрана. Камера їде за кораблем, тож точка під курсором весь час тікає вперед, і корабель летить без зупинок на повній швидкості, а не ривками від кліку до кліку.

**Бій.** Теж як у людини: клік по кораблю виділяє ціль (`MapManager.lockOnTarget`), `Ctrl` вмикає лазери (`toggleAttack`). Дистанцію гра сама не тримає, тому бот підлітає, коли ціль далі за `npcRange`. Коли з'являється потрібна коробка, бот летить по неї, лазери б'ють далі, поки NPC у радіусі, а після збору бот повертається до тієї ж цілі. Якщо HP і щит цілі не падають `npcStuckMs`, бот її кидає.

**Небезпечні NPC.** Тих, хто в `npcAvoid` (довгі боси), бот не чіпає: побачивши такого ближче за `npcAvoidDist`, відлітає, а коробок та інших NPC біля нього не бере.

**Відступ.** Коли HP падає нижче `retreatHpPct`, бот усе кидає, вимикає лазери й тікає від NPC — найперше від тих, що б'ють по ньому. Відірвавшись, стоїть, поки гра не відремонтує корабель до `retreatUntilHpPct`. Це працює і без бою з NPC: агресивні NPC нападають і під час збору коробок.

**Гейт.** Окремий режим головного циклу. Стрибок — клавіша `J`: гра шле запит, сервер переносить корабель, і клієнт створює героя заново; саме так бот і бачить, що вже прилетів. Конфігурація — клавіша `C`: гра й сервер дають міняти її раз на 5 с, номер приходить у `hero.config`, а щит у кожної конфігурації свій. Раунд зачищено, коли NPC нема, а на карті з'явились портали, яких не було до першої хвилі; лівий і правий бот розрізняє за координатою x. «Тягання» — це перетягування мишею, як і звичайний політ: курс щотіку відхиляється від цілі на кут, що залежить від відстані до неї, тож ціль тримається на `gateKiteDist`, якщо корабель не повільніший за неї.

**Фонова вкладка.** У прихованій вкладці браузер пригальмовує `setTimeout` до разу на секунду, а згодом і до разу на хвилину. Тому таймер бота працює у Web Worker — так само, як у рушії самої гри. Який таймер зараз працює, видно в `goBot.status().таймер`.

## Симулятор

Щоб перевірити зміни в боті без гри, у [`sim/`](sim) є симулятор: він запускає `main.js` у Node.js проти моделі гри. Клієнт у ній зроблено за кодом бандла гри (портали, `J`, `C`, `Ctrl`, політ мишею, новий герой після стрибка), сервер — за публічним емулятором (як NPC переслідують і б'ють, щит окремо для кожної конфігурації, ремонт через 10 с після бою), гейт — за описом: відлік, 4 хвилі, лівий і правий портали. Час віртуальний: 10 раундів проходять за кілька секунд, а той самий сід дає той самий прогін.

HP, швидкості й урон у моделі вигадані, а справжній сервер може поводитися інакше. Тож симулятор ловить помилки в логіці бота, але не обіцяє, що в грі все буде так само. Коробок у моделі нема.

Потрібен Node.js 18 або новіший.

```sh
node sim/suite.mjs                                     # усі сценарії й таблиця OK/ПРОБЛЕМА, кілька секунд
node sim/sim.mjs                                       # один гейт на 10 раундів з логом бота
node sim/sim.mjs --hard --seed=7                       # сильніші NPC, інша випадковість
node sim/sim.mjs --cfg='{"gateKiteDist":500}' --quiet  # як вплине інше налаштування
```

| Опція                     | Що робить                                                                    |
|---------------------------|------------------------------------------------------------------------------|
| `--seed=N`                | випадковість; той самий сід — той самий прогін                               |
| `--rounds=N`, `--from=N`  | скільки раундів у гейті й з якого почати                                     |
| `--hard`                  | NPC більше, і вони сильніші                                                  |
| `--nocfg`                 | сервер не шле номер конфігурації після стрибка                               |
| `--exitportal`            | у раунді від самого початку стоїть портал додому                             |
| `--lowhp`                 | на старті 60% HP                                                             |
| `--stopat=S`              | `goBot.stop()` через S с після старту гейта                                  |
| `--cfg=JSON`              | поміняти `goBot.config`                                                      |
| `--minutes=N`             | межа віртуального часу, за замовчуванням 60 хв на раунд                      |
| `--quiet`, `--json`       | тільки підсумок; тільки рядок JSON                                           |
| `--nostop`                | інший сценарій: `goBot.start()`, а тоді гейт без `goBot.stop()`              |
| `--restart`               | інший сценарій: `goBot.start()`, за мить `goBot.stop()` і одразу гейт        |
| `--far`                   | інший сценарій: корабель далеко від порталу, бот має відмовитись             |
| `--inside`                | інший сценарій: старт посеред раунду                                         |
| `--farm`                  | інший сценарій: звичайний режим, NPC на домашній карті й `startKillNpc()`    |

Код виходу: `0` — OK, `1` — проблема (корабель знищено, пройдено не всі раунди, помилки в консолі, бот почав діяти без команди, мишу водночас ведуть дві дії бота тощо), `2` — не вдалося запустити.
